# Plan 1-001 — Home and Category Redesign

**Area:** Android UI / UX  
**Priority:** P1  
**Depends On:** Existing Activities, Room article cache, category navigation, supplied redesign screenshot

**Objective**

Implement the screenshot-led redesign across the online and offline home experiences, and establish a consistent visual foundation for every article category screen.

**Acceptance Criteria**

The online home screen presents Today’s Briefing with six category cards matching the supplied redesign direction.  
Each category card displays its title, description, source, category gradient, and live cached article count from Room.  
The offline home screen uses the same card system and clearly communicates its offline state.  
Home, Offline mode, and Saved navigation actions remain functional through the redesigned bottom navigation.  
Each online and offline category screen uses the gradient associated with its corresponding home card.  
Existing category navigation, article fetching, Room caching, saved-article behavior, and WebView behavior remain intact.  
The UI supports system window insets without obscuring briefing or navigation content.  
The debug application builds successfully and local unit tests pass.

**Done When**

Users can move between the redesigned home, offline, saved, and category experiences while seeing consistent category styling and accurate cached article counts, with no regression to existing article workflows.

**Validation**

Run `./gradlew testDebugUnitTest assembleDebug` from the project root.  
Open the debug build and verify all six online category cards, all six offline category cards, category navigation, cached counts, and bottom-navigation actions.
