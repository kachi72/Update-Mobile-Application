# Plan 1-003 — Centralized App Executors

## Summary

Introduce a single application-wide executor provider and migrate manual threading so database, network, and UI work are dispatched consistently.

## Context

- **Area:** Android architecture / Concurrency
- **Priority:** P1
- **Dependencies:** Existing Room DAO calls, connectivity probes, WebView loading, offline category Activities
- **Source:** User-provided Android Open Source Project `AppExecutors` template
- **Target class:** `com.systemtech.update.helpers.AppExecutors`

## Implementation Plan

1. Create a thread-safe `AppExecutors` singleton in the new `helpers` package.
2. Configure a single-thread executor for ordered Room/database work.
3. Configure a three-thread pool for network operations.
4. Configure a main-thread executor backed by `Handler(Looper.getMainLooper())` so UI dispatch is centralized in one class.
5. Replace the manual database thread in `MainActivity.offline()` with `diskIO()` and replace its main-looper posts with `mainThread()`.
6. Replace connectivity and WebView network threads with `networkIO()` and return to UI work with `mainThread()`.
7. Replace manual database threads and main-looper posts in all six offline category Activities with `diskIO()` and `mainThread()`.
8. Remove obsolete `Handler`, `Looper`, and manual thread imports from migrated call sites.
9. Search the full application source to confirm direct thread creation and direct main-looper dispatch remain only inside `AppExecutors` itself.
10. Build, run local tests, and lint-check the migrated code.

## Scope Decisions and Discrepancies

- The template package is changed from `com.nichobox.honeywellcanteen.helper` to this application's `com.systemtech.update.helpers` package.
- The legacy support annotation is replaced with `androidx.annotation.NonNull`.
- The singleton reference is `volatile` so double-checked locking is safe.
- WorkManager workers keep executing on WorkManager-managed worker threads; only manually created threads are migrated.
- No `changes` directory or change markdown is created, per user direction.
